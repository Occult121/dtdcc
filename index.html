Types of attributes ---
1. Nominal attributes --- data order is not imp though imp is difference in data intervals
2. Ordinal attributes --- data order is imp though not imp is difference in data intervals
3. Interval attributes --- imp is data order + difference in data intervals
4. Ratio attributes ----imp is data order , difference in data intervals and a 0.0 where 0.0 = no data
